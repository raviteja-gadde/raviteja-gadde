## Ravi Teja Gadde

I'm a software engineer who likes to own the whole problem: the design, the code, the infrastructure it runs on, and what happens after it ships. Ten years in, across analytics platforms, payment systems, financial services, and now AI products, what I'm drawn to is hard design problems and building practical systems from the ground up, with decisions that still look right a few years later.

I'd rather understand a system down to the layer where it can fail than trust an abstraction I can't reason about. So I spend real time on the parts underneath an AI product: the data it stands on, the identity and access around it, the retrieval that feeds it, and the evaluation that says whether it works. When I learn something, I build it, check it against primary sources, and write it down so I can rely on it later. I'm making a habit of doing that work in public. Two deep dives so far:

- [data-engineering-labs](https://github.com/raviteja-gadde/data-engineering-labs) — data engineering by building: warehousing, columnar storage, dbt and Airflow, precomputation, suppression and access control, with runnable labs.
- [auth0-playbook](https://github.com/raviteja-gadde/auth0-playbook) — production authentication on Auth0: notes and runnable flows for OAuth/OIDC, federation, fine-grained authorization, and MCP server auth.

The next stretch of my work is agent systems: giving models tools, boundaries, and enough evaluation to trust them with real decisions. My day job is building exactly that at Gallup, where I took Gallup AI from first prototype to production; the architecture is in the AWS Architecture Blog post I co-authored, [Gallup delivers real-time workplace coaching to thousands of leaders with Amazon Bedrock](https://aws.amazon.com/blogs/architecture/gallup-delivers-real-time-workplace-coaching-to-thousands-of-leaders-with-amazon-bedrock/).

More at [raviteja-gadde.github.io](https://raviteja-gadde.github.io). Greater Phoenix Area.
